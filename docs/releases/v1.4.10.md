# Buddy2api v1.4.10

发布日期：2026-08-19

- 增加 DeepSeek V4 Pro / Flash 的可配置默认思考强度，Docker 默认使用 `high`；显式请求参数仍优先。
- 兼容 DSH 推理请求：将上游不接受的 `developer` 消息角色转换为 `system`，保留工具调用和流式输出。
- 收紧 HTTP 200 内容审查识别规则，避免正常回答引用审查文案时被误标为 `content_filter`。
- 增加思考强度、消息角色转换和内容审查识别的回归测试。

## 兼容与升级说明

- 无数据库结构变更，无迁移动作。
- Docker 用户重新构建并重启服务。
- 本版本不包含 zcode 等其他智能体的专门适配；上游内容审核行为仍由对应服务决定。
