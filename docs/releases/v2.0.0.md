# Buddy2api v2.0.0

发布日期：2026-08-25

多通道隔离网关。控制面可以跨通道扫描 / 导入 / 领取；数据面一次绑定一个通道，空仓返回 `channel_unavailable`，绝不静默切厂商。

## 功能

- WorkBuddy 仍是默认通道；存量 Key 绑定 `workbuddy`，未加前缀的 `auto` / `glm-5.2` 行为与 1.4.10 相同。
- QClaw、QwenWork 适配器可合入仓库，**默认 registry 不含它们**。启用方式：`CB_GATEWAY_PROVIDERS=workbuddy,qclaw` 或 `workbuddy,qclaw,qwenwork`。QwenWork `qwork-advanced` 已在官方 0.1.8-26081406 冒烟 200。
- 每把 API Key 必须选择通道，管理页下拉可切换。
- 启动默认只检测本机登录文件，不自动入库。`CB_GATEWAY_AUTO_IMPORT=1` 恢复旧行为。
- Dashboard 按通道展示剩余额度，`total_balance` 恒为 `null`。
- Docker helper 在 WorkBuddy auth 目录缺失时继续启动，不再 `exit 1`。Linux 容器读不了 Windows DPAPI，跨 OS 共享库请设 `CB_GATEWAY_MASTER_KEY`。

## 兼容与升级说明

- 空仓：预留配额前 503 `type/code=channel_unavailable` **不扣** API Key 日限额；预留后耗尽仍扣次。
- 裸 `qwork-advanced` 等外通道 id 在 WorkBuddy Key 上 **400**。
- 创建 Key 不选通道 **400**。
- 数据库新增 `accounts.provider`、`accounts.extra`、`api_keys.default_channel`；`init_db` 自动迁移。
- QwenWork 按官方 0.1.8-26081406 桌面端行为冻结。
