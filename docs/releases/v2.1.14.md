# Buddy2api v2.1.14

发布日期：2026-09-21

小版本：管理页能核对是不是最新版，有新版本时顶栏出现更新按钮，git 克隆可一键拉取并重启。对应 [#80](https://github.com/wicm84266964/Buddy2api/issues/80)。

## 版本更新

- 打开管理页后在后台核对远端 `version.py`，优先走 jsDelivr，GitHub 只是后备。
- 核对失败保持安静，页面和网关都不受影响。
- 发现新版本时顶栏出现「更新到 vx.y.z」；设置页也可以检查更新。
- git 克隆、当前在 `main`、工作区没有已跟踪改动时，一点就会 `git pull --ff-only`、安装依赖并重启。
- Docker、zip 解压或不在 `main` 上时，按钮会说明原因，仍可用 README 里的手动步骤。
- 本机已是最新、只想看按钮：启动前设 `CB_GATEWAY_FAKE_LATEST=9.9.9`，点下去不会真的拉取或重启。

## 升级说明

- 无数据库迁移。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不要改 `web/index.html` 里的版本字符串。
