# Buddy2api v1.4.0

发布日期：2026-07-14

这是从 `v1.3.0` 之后的中版本更新，重点覆盖 OpenAI Responses API 兼容、安全加固、Docker 部署体验和管理界面升级。

## 主要更新

- 新增 `/v1/responses` Responses API 兼容层，可将 Responses 请求转换为上游 Chat Completions，并支持流式事件映射。
- 增强 Codex 兼容：模型别名映射、内容字段清洗、developer 角色兼容和非 function 工具过滤。
- API Key 增加模型权限与每日请求额度校验，额度预留采用原子操作，避免并发请求超限。
- 账号凭据写入 SQLite 前加密，支持跨平台主密钥或权限受控的本地密钥文件；旧数据启动时自动迁移。
- 增加请求体大小限制、CORS 来源白名单、日志保留周期和安全 Cookie 配置项。
- Docker 使用固定基础镜像摘要、非 root 运行和健康检查；Windows/WSL 启动脚本支持只读挂载本机 auth 目录。
- 管理后台改为深色顶栏和暖橙工作台风格，新增经典/橙色/森林主题、移动端响应式布局和可滚动宽表格。
- Dashboard 增加官方额度汇总、到期提醒、请求/Token/Credit 热力图和更紧凑的运行指标。
- 请求日志支持关键词、状态、模型筛选、分页和详情展开；设置页增加常用客户端接入向导。
- 增加测试配置和覆盖核心安全/兼容路径的测试集，当前共 10 项。

## 兼容与升级说明

- 建议在迁移数据库或更换容器时固定 `CB_GATEWAY_MASTER_KEY`，避免跨环境无法解密凭据。
- 没有配置 API Key 时，默认拒绝业务请求；仅在本机兼容旧调用时显式设置 `CB_GATEWAY_ALLOW_UNAUTHENTICATED_API=1`。
- Web UI 默认通过同源 HttpOnly Cookie 管理后台认证，远程或异常场景仍可使用 `CB_GATEWAY_ADMIN_TOKEN`。
- Docker 对外端口默认绑定 `127.0.0.1:8787`，如需远程访问请自行配置网络边界和认证策略。
