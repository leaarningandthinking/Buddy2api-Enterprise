# Buddy2api v2.1.12

发布日期：2026-09-18

小版本：管理页和启动横幅都从 `version.py` 读版本号，避免网页、CLI、发版号再各写一份。对应 [#70](https://github.com/wicm84266964/Buddy2api/issues/70)。

## 版本号

- 管理页标题不再写死 `v2.1.x`，打开首页时注入 `version.py` 的 `VERSION`。
- 命令行启动横幅本来就读 `VERSION`，本版保持这一处来源。
- 发版仍只改 `version.py`、README 和本说明；不要再改 `web/index.html` 里的版本字符串。

## 升级说明

- 无数据库迁移。
- Docker 用户需要重新构建镜像并重启服务。
