# Buddy2api v2.1.8

小版本：把 2.1.7 之后已合进 `main`、但没打进安装包的改动，和 Dashboard 优化一起发出。

- WorkBuddy 与其它通道一样：官方目录只读，自定义走「添加模型」，手动项在一键读取后保留。
- 不再单独编辑 WorkBuddy 模型表；「保存别名」只存别名。

## Dashboard

- 进入不再整页等待官方额度：先渲染统计图表，额度卡片后台补齐。
- 各通道额度并行读取；未强制刷新时 WorkBuddy 额度缓存 5 分钟。
- 今日用量改为近 7 日折线，带日期横轴、数值纵轴；圆点不再被拉扁。
- 24 小时改为折线；今日质量和模型占比用饼图。质量、接入说明的排布顺了一下。
