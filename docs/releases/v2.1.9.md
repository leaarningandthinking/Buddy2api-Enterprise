# Buddy2api v2.1.9

发布日期：2026-09-15

小版本：修好 TraeWork 正文解析、Responses 流式转换，并给 WorkBuddy 工具循环补一层停转重试。

## TraeWork 解析

- 可见回复从 `finish` 工具的 `params.summary` 读取；思考留在 `reasoning_content`，不再写进 `content`。
- DeepSeek-V4-Flash-Official 不再报 `TraeWork turn finished without assistant text`。
- usage 从会话消息上的 `token_usage` 填写，不再写死全 0。
- 对应 [#64](https://github.com/wicm84266964/Buddy2api/issues/64)。

## Responses 桥

- TraeWork 流式块可以是字符串或 bytes，`/v1/responses` 不再抛 `upstream stream chunks must be bytes`。
- TraeWork 流式输出改为 bytes，与其它通道一致。
- 对应 [#62](https://github.com/wicm84266964/Buddy2api/issues/62) 里目录更新之后仍无法调用的那截。TraeWork 仍无 OpenAI 工具循环。

## 工具停转

- 流式工具循环若 `stop` 且未调工具，会像非流式一样用 `tool_choice=required` 再打一次。
- 短的非总结回复（含英文确认话术）也会当成停转。
- 对应 [#61](https://github.com/wicm84266964/Buddy2api/issues/61) 的防护；长上下文开放任务里模型自己提前收工，不保证消掉。

## 升级说明

- 无数据库迁移。
- Docker 用户需要重新构建镜像并重启服务。
- 思考强度策略未改。
