# Buddy2api v1.4.4

发布日期：2026-07-25

这是 `v1.4.3` 的小型兼容性修复，解决腾讯上游流式工具调用经 sub2api 转发时被 Buddy2api 提前中止的问题。

## 主要更新

- 兼容腾讯上游在工具参数续传分片中重复返回空字符串 `function.name` 的行为，将空名称视为本分片未重复工具名并继续组装参数。
- 继续拒绝非字符串工具名，并保留流结束时对调用 ID、最终非空工具名和 JSON 对象参数的完整性校验。
- 新增与真实上游顺序一致的回归测试，覆盖初始工具名、空名称续传、分段参数、空中间 `finish_reason`、最终 `tool_calls` 和单个 `[DONE]`。

## 兼容与升级说明

- 本次没有数据库结构迁移，已有账号、密钥和数据目录可以直接复用。
- Docker 用户需要重新构建并重启服务：`docker compose up -d --build`。
- sub2api 保持现有 `http://host.docker.internal:8787/v1` 账号配置即可，无需修改 Lab Agent 请求格式。

## 验证

- `python -m compileall -q .`
- `python -m pytest -q`：72 passed
- 真实链路 `Lab Agent -> sub2api:8080 -> Buddy2api:8787 -> 腾讯上游` 已完成多工具流式调用和工具结果回传，未出现 502、503、解析错误或重复终止事件。
