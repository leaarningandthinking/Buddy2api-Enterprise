# Buddy2api v2.1.15

发布日期：2026-09-24

小版本：千问办公对话不再固定返回 `503 Model catalog unavailable`。对应 [#82](https://github.com/wicm84266964/Buddy2api/issues/82)。

## 千问办公

- 1.0.4 网关用请求体 `business.product` / `business.type` 解析模型目录。只带 `Cosy-Business-*` 头时，登录、积分、模型列表都正常，对话仍会 503。
- 对话 body 现与这两个头同源：`qoder_work` / `agent`。
- 推理请求改走官方 `Encode=1` 组包，依赖新增的 `wasmtime`。

## 升级说明

- 无数据库迁移。
- 请重新安装依赖（`python -m pip install -r requirements.txt`），然后重启进程。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不要改 `web/index.html` 里的版本字符串。
