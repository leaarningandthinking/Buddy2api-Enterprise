# Buddy2api v1.4.6

发布日期：2026-08-10

这是 `v1.4.5` 的安装与密钥管理体验修复版本，重点解决启动脚本在其他设备上无法定位 Conda 环境、需要手动安装依赖，以及客户端 API Key 创建后无法再次复制的问题。

## 修复内容

- Windows 启动脚本改为纯 ASCII，避免部分 `cmd.exe` 代码页把中文提示错误解析为命令。
- `start.bat` 和 `start.sh` 会优先查找 Conda，并自动创建或复用名为 `buddy2api` 的 Python 3.12 环境。
- 即使尚未执行 `conda init`，脚本也会检查常见的 Miniconda、Anaconda 安装目录；找不到 Conda 时自动回退到项目内 `.venv`。
- 启动前自动检查并安装 `requirements.txt` 中缺少的依赖，完成后直接启动 Buddy2api；环境创建、升级或依赖安装失败时会明确报错并停止。
- API Key 继续使用 SHA-256 哈希进行请求鉴权，同时单独加密保存完整 Key，使其可以在受 Admin 鉴权保护的管理页中再次查看和复制。
- API Keys 页面增加完整 Key 的显示、隐藏和复制操作；Codex 一键配置会自动选用首个可恢复的 Key。
- 补充中英文 README，加入从安装 Git、克隆仓库、创建 Conda 环境到启动与升级的完整新手命令。

## 兼容与升级说明

- 新版本首次启动时会自动为 `api_keys` 表增加 `key_secret` 字段，无需手动迁移数据库。
- 旧版本已经创建且只保存哈希的 Key 无法逆向恢复，但仍可正常鉴权；如需在管理页复制完整 Key，请重新创建一个 Key。
- 旧数据库中仍以明文保存的历史 Key 会自动迁移到加密存储。
- 本机启动可直接双击 `start.bat`；Linux/macOS 执行 `chmod +x start.sh && ./start.sh`。
- Docker 用户需要重新构建并重启服务：`docker compose up -d --build`。
