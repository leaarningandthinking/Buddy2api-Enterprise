# Buddy2api v2.1.16

发布日期：2026-10-06

小版本：TraeWork 签到和积分在 access token 过期后可以继续领取。对应 [#86](https://github.com/wicm84266964/Buddy2api/issues/86)。

## TraeWork

- 签到和积分查询发现 access token 过期，或上游返回认证失败时，先用 refresh token 换票再重试。
- 积分余额改读官方 `user_entitlement_pack_list`，不再只看空的 `usage_summary`。
- 账号行上的「领取」走 TraeWork 自己的签到接口，不再打到 WorkBuddy。
- refresh token 也失效时，提示打开官方客户端重新登录后再导入。

## 升级说明

- 无数据库迁移。
- 重启进程即可。已导入的账号如果 refresh token 仍有效，下次领取会自动换票。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不要改 `web/index.html` 里的版本字符串。
