# Buddy2api v1.4.1

发布日期：2026-07-15

这是 `v1.4.0` 的界面与统计体验更新，重点改善 Dashboard 当日用量展示，并清理管理后台中没有业务含义的复刻控件。

## 主要更新

- Dashboard 新增全账号今日额度消耗、调用次数和 Token 汇总，保留官方余额、成功率、单次均耗和累计值作为辅助信息。
- 新增今日 24 小时使用趋势图，可在调用次数、Token 和额度消耗之间切换。
- 管理统计接口新增 24 个本地时间小时桶；无调用的时段补齐为 0，避免前端推算或遗漏空档。
- 顶栏移除主题复刻按钮、硬编码节点标识和重复齿轮入口，只保留有效的刷新操作。
- 备用 Admin Token 移至设置页，支持保存和清除，并同步修正管理凭证错误提示。
- 修复设置页已有 API Key 时引用错误变量导致弹出“加载失败”的问题。
- 优化桌面和移动端响应式布局，今日用量与小时趋势图在窄屏下不会横向溢出。

## 兼容与升级说明

- 本次没有数据库结构迁移，已有数据目录可以直接复用。
- Docker 用户需要重新构建镜像才能加载新版前端和小时统计逻辑：`docker compose up -d --build`。
- 今日统计按运行实例的本地时区聚合，范围为当天 00:00 至当前时间。
