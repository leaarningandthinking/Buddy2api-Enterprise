# Buddy2api v1.4.2

发布日期：2026-07-25

这是 `v1.4.1` 的小型稳定性更新，重点修复智能体通过 Responses API 调用工具时，流式事件被网络分片截断后可能产生不完整调用命令并中断的问题。

## 主要更新

- 重构上游 SSE 事件缓冲，完整处理任意 HTTP/UTF-8 字节分片、LF/CRLF/CR 换行、注释行和多行 `data:` 字段。
- 按 Responses API 标准输出 `response.function_call_arguments.delta` 与 `response.function_call_arguments.done`，确保工具参数可被智能体完整组装。
- 隔离并行 choice 与并行工具调用的状态，保留上游 `call_id`，避免多个工具调用之间串流或覆盖。
- 补齐文本与工具调用的生命周期事件；只有所有已出现的 choice 都正常结束后才返回成功。
- 对长度限制和内容过滤返回 `response.incomplete`；对参数损坏、上游错误和意外 EOF 返回 `response.failed`，避免把半截工具参数误报为完成。
- 为单行和单个 SSE 事件增加 8 MiB 安全上限，避免异常上游数据导致缓冲区无限增长。

## 兼容与升级说明

- 本次没有数据库结构迁移，已有配置和数据目录可以直接复用。
- Docker 用户需要重新构建并重启服务：`docker compose up -d --build`。
- 使用 Responses API 工具调用的客户端无需修改请求格式。
