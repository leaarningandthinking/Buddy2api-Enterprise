# Buddy2api v2.1.13

发布日期：2026-09-20

小版本：WorkBuddy 国际号按自己的站走、出站统一补 system、PyCharm 2025.1 调试能启动。对应 [#73](https://github.com/wicm84266964/Buddy2api/issues/73)、[#75](https://github.com/wicm84266964/Buddy2api/issues/75)、[#76](https://github.com/wicm84266964/Buddy2api/issues/76)。方案移植自 [lyston11](https://github.com/lyston11/Buddy2api)。

## WorkBuddy 国际 / 国内

- `backend_url(account=None)`：没账号或缺 `domain` 时仍用设置项。
- 国内号继续走原来的后端；`www.workbuddy.ai` / `workbuddy.ai` 改打 `https://www.workbuddy.ai`。
- 聊天、首页测试、刷新 token、额度、签到、模型目录都按账号选。
- Origin/Referer 只认 `*.workbuddy.ai` 为国际版，不再把 `www.workbuddy.cn` 当成 `.ai`。

## 出站 system

- `build_backend_body` 在 `developer → system` 之后，若首条不是 system 就插入一条，首页测试和正式聊天同一条路径。
- `CB_GATEWAY_SYSTEM_PROMPT=off` 可关。

## PyCharm

- 普通 `python server.py` / Docker 仍走 `server.run()`。
- 只有 pydevd 把 `asyncio.run` 换掉时才手写 loop，避开 uvicorn 0.52 的 `loop_factory`。

## 升级说明

- 无数据库迁移。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不要改 `web/index.html` 里的版本字符串。
