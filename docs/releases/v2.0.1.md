# Buddy2api v2.0.1

发布日期：2026-08-25

默认打开三个通道，避免还要先改环境变量。

## 功能

- 未设置 `CB_GATEWAY_PROVIDERS` 时，registry 为 `workbuddy,qclaw,qwenwork`。管理页账号 / Key 下拉默认三项。
- 没登录的通道检测为空，仍不自动入库。
- Docker 里选 QClaw / 千问办公时，账号页说明 Linux 容器解不开 Windows 登录文件，请用本机 `python server.py`。WorkBuddy 继续走容器。
- 仍可用 `CB_GATEWAY_PROVIDERS=workbuddy` 收窄到一家。一把 Key 只打一个通道，不会跨厂切换。
