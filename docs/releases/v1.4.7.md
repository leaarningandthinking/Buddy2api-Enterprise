# Buddy2api v1.4.7

发布日期：2026-08-18

这是 `v1.4.6` 的轻量修复版本，包含两项改动：

## 修复内容

- **出站请求不再自曝网关身份**（issue #30）：转发到上游后端的 `User-Agent` 从 `buddy2api/1.4.6` 改为通用浏览器 UA，避免调用方一眼分辨出代理流量。需要自定义时可通过环境变量 `CB_GATEWAY_USER_AGENT` 覆盖。
- **Codex 清洗增加特征门**：`client_type=codex` 的 API Key 只对携带 Codex 特征标记（如 `<permissions instructions>`、`Escalation Requests`）的请求执行敏感词清洗。DSH、OpenClaw 等其他客户端借用 codex key 时请求原样透传，不再出现 system prompt 被 1200 字符兜底规则整体替换、导致 agent 丢失工具指令退化为纯对话的问题。

## 兼容与升级说明

- 无数据库结构变更，无迁移动作。
- 现有部署无需调整配置；如需自定义 UA 设置 `CB_GATEWAY_USER_AGENT` 即可。
- Docker 用户重新构建并重启服务：`docker compose up -d --build`。

## 验证

- `python -m pytest -q`：86 passed。
- 新增测试覆盖：非 Codex prompt 原样透传、Codex prompt 仍被清洗、无 system message 时透传。
